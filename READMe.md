# 📚 NetNinja Pro – The Book

A responsive book landing page built as a front-end web development project.

## 🌐 Live Demo

[View NetNinja Pro Live](https://sunshine-1812.github.io/netninjapro/)

## 📖 About the Project

NetNinja Pro is a responsive landing page for a book. The project focuses on creating a clean, modern, and responsive user interface using HTML, CSS, Bootstrap, and Sass.

The website includes sections for the book introduction, topics, reviews, pricing, and contact information.

## ✨ Features

- Responsive navigation bar
- Sticky navigation bar
- Responsive layout using Bootstrap
- Custom Bootstrap theme using Sass
- Book cover and visual content
- About the book section
- Reviews section
- Pricing section
- Contact section
- Bootstrap Icons
- Mobile-friendly navigation menu
- Smooth and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Sass (SCSS)
- Bootstrap Icons
- Git
- GitHub
- GitHub Pages
